# 🌤️ Weather Dashboard App

A responsive React application that allows users to search for real-time weather conditions and a 5-day forecast using the [OpenWeatherMap API](https://openweathermap.org/api).

---

## 🚀 Features

- 🌆 Search weather by city
- 📍 Get weather using current location
- 🔁 Recently searched cities (saved in localStorage)
- 📅 5-day forecast with icons and data
- 🌐 Fetches data from OpenWeatherMap API
- 💅 Custom CSS styling 

---

## 🛠️ Tech Stack

- ⚛️ React (Functional Components + Hooks)
- 🎨 Custom CSS 
- 🌐 OpenWeatherMap API
- 🔐 Environment variables for API key

---

## 📦 Installation & Setup

1. **Clone the repository**

git clone https://github.com/your-username/weather-dashboard-react.git
cd weather-dashboard-react

2. **Install dependencies**
   
 npm install
 
3. **Add your OpenWeatherMap API key**
   
  Create a .env file in the root of the project:
  

     REACT_APP_OPENWEATHER_API_KEY=    ***add your apt key here***

4. **Start the development server**
   
 npm start
